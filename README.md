# Gym Manager Front

Frontend em Angular para o sistema Gym Manager — uma aplicação web para personal trainers gerenciarem alunos e treinos.

## Tecnologias
- Angular 20+
- TypeScript
- SCSS (com Tailwind CSS)
- HTML/CSS

## Funcionalidades (em desenvolvimento)
- Cadastro e login de usuários (alunos e personal)
- Gerenciamento de planos de treino personalizados

## Como rodar
1. Clone o repo: `git clone https://github.com/marikanashiro/gym-manager-front.git`
2. Entre na pasta: `cd gym-manager-front`
3. Instale dependências: `npm install`
4. Rode o servidor dev: `ng serve`
5. Acesse: http://localhost:4200/
